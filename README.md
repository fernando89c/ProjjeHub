# ProjjeHub

Sistema de gerenciamento de projetos e tarefas desenvolvido com React e Node.js.

## Estrutura do Projeto

- `frontend/`: Aplicação React
- `backend/`: API Node.js

## Requisitos

- Node.js 18+
- MySQL

## Instalação

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## Tecnologias Utilizadas

- Frontend:

  - React
  - Next.js
  - Tailwind CSS
  - Shadcn/ui

- Backend:
  - Node.js
  - Express
  - MySQL
  - Prisma
