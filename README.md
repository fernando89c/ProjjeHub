# ProjjeHub

Sistema de gerenciamento de projetos e tarefas.

## Estrutura do Projeto

- `frontend/`: Aplicação Quasar/Vue.js
- `backend/`: API Node.js

## Requisitos

- Node.js 18+
- MySQL

## Instalação

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## Tecnologias Utilizadas

- Frontend:

  - Vue.js 3
  - Quasar Framework v2
  - TypeScript
  - Vite
  - Vue Router

- Backend:
  - Node.js
  - Express
  - MySQL
  - Prisma
